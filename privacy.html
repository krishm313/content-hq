Privacy policy

Last updated: October 31, 2026

Content HQ is a personal tool that runs only on its owner's computer and uploads the owner's own videos to the owner's own YouTube channels. This policy explains what it does with data from Google.

Use of YouTube API Services

Content HQ uses YouTube API Services. By connecting a YouTube channel to Content HQ you agree to the YouTube Terms of Service. Google's handling of your data is described in the Google Privacy Policy.

What data is accessed

  • The connected channel's ID, name and handle, so the tool can show which channel it posts to.
  • The status of videos it uploaded (processing, scheduled, published), so it knows when an upload is finished.
  • OAuth access and refresh tokens issued by Google, so it can upload without asking you to sign in every time.

Content HQ does not access comments, analytics, subscribers, other channels' data, or any data from people who watch the videos.

How it is used and stored

All of this data stays on the computer where Content HQ runs. Tokens are kept in a private file in the user's home folder. Nothing is sent to any server other than Google's, and nothing is sold, shared, or used for advertising. The tool sets no cookies and collects no information from visitors to this website.

How to remove access

Click Disconnect in Content HQ (Settings → Publishing), which deletes the stored tokens and asks Google to revoke them. You can also revoke access at any time on Google's third-party access page.

Changes and contact

If this policy changes, the date above is updated. Questions can be raised on this site's GitHub page.
